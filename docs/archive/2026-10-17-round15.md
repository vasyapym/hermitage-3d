## Hunt / found / fixed
Adjudications that shaped the chain:

gltf-transform 4.5.1's meshopt layout is ONE real buffer (fallback + compressed chunks, ext offsets absolute in buffer 0) plus a trailing {fallback:true} declaration. Its .gltf writer keeps that chunk uri-less, so data is dropped; therefore every chain ENDS .glb.
repackBin (new in common) flattens to the strict single-buffer GLB, remaps accessor bufferView indices + meshopt ext offsets and drops embedded-image weight.
Determinism ≠ validity: the sha double-run had passed while the canary file was invalid.
prune keeps TEXCOORD_1 via --keep-attributes (the flag takes attribute NAMES, not a boolean).
KTX2 magic byte 8 is 0xBB (the draft had 0xAB twice).
The generic test fence now validates EVERY committed room (schema + sha recompute + single-buffer GLB).
Transport MASKED numbers: restored against cfea363; MASKED-marker protocol adopted.
