## Hunt / found / fixed

THE BISECT, the reported «black interiors under 'a'». The runtime was exonerated layer by layer with empirical probes:

17b ≡ 17c in a 4-cell matrix.
All three techniques are equally dark with the seam on.
uv1 alive (a synthetic UV-grid rendered on the walls).
The GPU ktx2 decode ≡ the stage PNG row-by-row.
ETC1S killed only 0.7% of surviving samples.
Material bindings correct.


Cause = the CONTENT:

The day bake's indirect is nearly absent at the walls (56% of the EXR < 0.001 linear). The J0 view is the under-stair vestibule, which the bake legitimately leaves dark.
ONE night-tuned white point per room quantised the remaining field to codes 0–2, which ETC1S finished.
Fix = the r17c scalar law (see Verdicts).


b-rt had never actually worked: channel-1 maps sampled the plane's missing uv1, giving a black RT. Fixed (see Verdicts).
The measurement's first run measured config 1 three times. A fragment navigation remounts nothing, so a fresh page per config is the fix. A new transport trap was recorded in STATE.md.
