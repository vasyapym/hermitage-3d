## Verdicts
Accepted near-wholesale, one orchestrator adaptation.

Precedence: dwell > suppressed > gliding > rest.
The glide fades out HOLDING the departure text and swaps only on landing while hidden. A midpoint swap was rejected because it would couple the UI core to the rail's progress. The law's precondition is CAPTION_FADE_MS < the shortest glide holds: 240 < 320.
The dwell shows the destination's seed-stop caption. The hand-over to the rest frame reports zero changes (no flash, tested).
The announcement <id> · <caption> is sticky (hide never clears; ATs would not re-announce identical text anyway) and rewrite-on-change via captionChanges.
Malformed committed data fails loud (static data = programmer errors, not runtime degradation).
The overlay is aria-hidden and mirrored by a role="status" sr-only live region.
#scene becomes the focusable surface (tabindex 0, aria-label, describedby → sr-only help + the live region). role="application" was REJECTED because it suppresses AT browse-mode keys page-wide.
Orchestrator adaptation: the CSS snippet's token names (--scrub-block-height/--overlay-fg) do not exist, so it was restyled with the file's literal tokens (the timeline's 14px, rgba tones, bottom 52 px above the 32 px scrub).
Integration:

The dwell caption is single-sourced from the seed law (seedInputs shared by seedRail and dwellStop). The dark card shows exactly the stop the frame will rest on, backward entries included.
The caption binds per frame with write-on-change (no throttle; the writes are change-gated).
suppressed = arrival.phase !== 'settled' (the specialist's recommendation).


e2e:

Every keyboard-walk landing asserts its §6.1 beat text + data-stop.
The live region tracks the walk's ends (J4 forward / S0 backward).
The graph walk asserts the dwell hand-over text.
Goldens hide #caption.
