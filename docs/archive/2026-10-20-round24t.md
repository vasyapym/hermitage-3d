## Hunt / found / fixed
THREE FACTS LEARNED:

The OFL carries the Reserved Font Name "Plex", so the subsets are renamed to the project-local WP Sans / WP Serif. Name-table law: rewrite 1/3/4/6, keep the copyright/trademark/license notices verbatim. A post-subset scan fails loud on any surviving Plex name.
The Plex sources carry NO tnum/pnum/mkmk GPOS features and need none: every digit measures a uniform 600/1000 em, tabular by default. So the §2.2 tnum styling is satisfied by the defaults, and the §2.1 feature list degenerates to keep-what-exists (kern/liga/locl/ccmp/mark).
woff2 container bytes vary a few encoder bytes run-to-run while every sfnt table stays byte-identical. The determinism claim is font-level; the committed files are canonical.
