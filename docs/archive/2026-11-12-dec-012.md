## Verdicts
### DEC-012 — Playwright e2e: CI smoke on software GL, goldens local-only

Verdict, CI: the budget table's "HUD + Playwright assertion" rows run on every push. They cover:

det T1/T0 boots reading the HUD data-* contract;
a clean console;
generous hang bounds.


Verdict, goldens:

Pixel goldens are rendered only on the reference Mac's real GPU, with committed platform-suffixed baselines.
This is the charter's documented fallback, adopted deliberately.
Software-GL output is deterministic per machine but baselines are not portable.
The headless compositor throttles cadence (~200 ms median vs 16.6 headed on the same build/GPU; tag n/r).
So CI can never vouch frame cost.


Round 11 also proved that a locator screenshot never passes element stability on a rAF-driven WebGL canvas. Goldens therefore capture page-level with a clip (docs/adr/0012.md).
Rejected alternatives:

CI goldens with generated software-GL baselines: double the baseline surface and still not the real GPU.
A runtime watchdog built this round: golden frames had to exist first.
