   in the same thread, never one monologue — stage 1 = the assessment/design draw, complete in

6. THE PATH TABLE AND THE ENUMERATE-FIRST SWEEP (owner, 2026-11-25; the bake9–11 precedent —
   one bug, three symptoms, three box runs). A relay design that introduces or moves FILE
   PATHS ships with a PATH TABLE: file family → written by (the resolved path) → read by
   (the resolved path); ONE canonical location per family (the round's precedent: the stage
   ROOT beside summary.json — never the per-state dirs, whose names belong to bake.mjs's own
   law). The integrator verifies the table against the committed code like the sources,
   resolves every named uncertainty ONCE before wiring (recorded in the integration notes,
   applied everywhere — a per-call-site resolution costs one box run per seam), and runs the
   ENUMERATE-FIRST sweep before the first box run: grep every new file name and env var
   across the touched tree and list every writer and reader with its resolved path — all
   sites agree → file the run; a disagreement → fix locally, no run. The readout contract
   cites only OBSERVABLE signals: check which drivers capture stdout before filing (bake.mjs
   captures — only the ZIMNY_SUMMARY line goes up; asset.mjs and reencode.mjs echo; the
   layout-identity proofs live in the stage summary + the bake-summary sidecars + the
   manifest row, not in chain.log).
7. THE MEASURED BRIEF (owner, 2026-11-26; the rgnext-7 precedent — the sitting's panel/head

8. THE MEMORY LAW (owner, 2026-11-26; the rgnext-7 round's six graze slivers — three box
   cycles spent measuring what the records already held). The dead-cell gate gets MEMORY:
   the check reads the LAST INGESTED bake's dead set from the committed bake log
   (tools/bake-logs/<room>.json, postEncode.<day-state>.deadCells); the STABLE darkness
   (dead in the memory too) = the advisory class — printed, never gating; the NEW darkness
   = fails exactly as before. The memory is written ONLY at ingest (the acceptance): the
   ingesting agent adds the done bake's dead set to the bake log in the ingest commit. The
   memory's absence or tampering = the strict fail-closed fallback. The teeth stay: a lit
   cell going dark is the NEW darkness at its own bake, never the advisory.
9. THE SMOKE TEST BEFORE THE BOX (owner, 2026-11-26; the bake18/19 precedent — two box
   cycles spent on a mystery the local harness already held the answer to: the seeded
   memory sat in the tree while the check read a key the log writer had dropped). A change
   to a gate, a log writer or the wiring between them carries its LOCAL synthetic smoke
   test BEFORE any box filing, and the smoke test's result rides the commit message: the
   happy pass, the tampered fail (the teeth), and the round-trip (write → read → every
   foreign key survives). A box run proves only what the local harness cannot — the box's
   environment, the real bake, the timing — never the logic; a RED whose cause the local
   harness can reproduce is filed with the reproduction attached, not discovered on the box.
